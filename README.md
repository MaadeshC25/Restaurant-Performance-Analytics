# Restaurant Performance & Operations Analytics

Operational analytics dashboard evaluating profitability and delivery performance across 6 restaurant outlets, built using SQL and Power BI.

## 📊 Project Overview
This project analyzes transactional and menu datasets to identify top-performing dishes, profit margins, and peak delivery periods across multiple restaurant outlets.

## 🛠️ Tools Used
- **SQL** – Data analysis, querying transactional & menu datasets
- **Python** – Data cleaning and preparation
- **Power BI** – Interactive dashboard & visualizations

## 🔍 Key Insights
- Identified top-performing dishes and profit margins per outlet
- Analyzed revenue trends and fulfillment rates
- Mapped peak delivery periods to optimize logistics
- Delivered recommendations for menu optimization and resource allocation to improve branch profitability

## 📁 Files in this Repository
- `restDatapython.py` – Python script for data cleaning
- `SQLqueryRestaurant.sql` – SQL queries for transactional analysis
- `RestaurantPerformanceDash.pbix` – Power BI dashboard file
